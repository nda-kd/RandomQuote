# 🎲 RandomQuote

A simple and fun Random Quote Generator that displays quotes to inspire, motivate, and encourage you.

## 🌐 Live Demo

Check out the live version of RandomQuote: [Live Demo](https://nda-kd.github.io/RandomQuote/)

## ✨ Features

- 🎯 Generate random quotes.
- 💬 Discover inspiring and motivational messages.
- 🎨 Simple and user-friendly interface.
- ⚡ Quick and easy to use.

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need a modern web browser and Git installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/nda-kd/RandomQuote.git
   ```

2. Navigate to the project directory:

   ```bash
   cd RandomQuote
   ```

3. Open the project in your browser.

   If it is a static web project, open the `index.html` file. Alternatively, use the Live Server extension in Visual Studio Code.

## 📖 How to Use

1. Open the RandomQuote application.
2. View the displayed quote.
3. Use the available controls to generate another quote.
4. Enjoy discovering new quotes!
